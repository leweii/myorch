# Fonts of the docs pages

Self-hosted so `docs/index.html` and `docs/workflows/index.html` need no network. Both are variable
fonts (weights 100–900), Latin subset, from [Fontsource](https://fontsource.org/):

| File | Font | License |
|---|---|---|
| `inter-tight-latin-wght-normal.woff2` | [Inter Tight](https://github.com/rsms/inter) | SIL Open Font License 1.1 |
| `geist-mono-latin-wght-normal.woff2` | [Geist Mono](https://github.com/vercel/geist-font) | SIL Open Font License 1.1 |

Chinese text falls back to the system fonts (PingFang SC, Noto Sans SC, Microsoft YaHei).
